P A R T  1

等差数列は、
一定の歩幅で進む数列。

数を一列に並べたものを 数列という。 そのうち、 となりとの差がいつも同じ ── 一定の歩幅 d を足し続けるのが 等差数列。 n 番目の数を一発で出す 一般項と、 最初から n 番目までを合計する 和の公式を学ぶ。

数の列の規則を、

この数列は、 第 1 項が 2、 となりとの差がいつも ＋3。 先頭の 2 に、 3 を (n − 1) 回足せば第 n 項になる。 たとえば第 5 項は 2 ＋ 3 × 4 ＝ 14、 第 100 項なら 2 ＋ 3 × 99 ＝ 299。 一定の差で進むこの形を、 次のスライドで 等差数列として一般化する。

一般項と和の公式は、 計算問題のためだけのものではない。 毎月の返済が一定になる 分割払いも、 生き物の数が増える 人口増加モデルも、 数列の言葉で書ける。 等差・等比の公式が、 お金と社会の予測にそのまま使える様子を見る。

段階を0 と 1で表す。

第 II 部の流れを 1 枚にまとめる。 なめらかな量を一定間隔で測って段階に丸め（標本化・量子化）、 その段階を 2 進数（0 と 1）で書く。 段階を何通り用意できるかは ビット数で決まり、 n ビットで 2 の n 乗通り。 これが、 写真も音も文字も同じ「0 と 1 の列」 で扱える理由である。

本日は 2 部構成だった。 第 I 部の 数列と、 第 II 部の デジタル表現と情報量。 それぞれの要点を、 3 つの原理にまとめる。

FLOW ／ 今日の流れ
01

数列は、 規則をもった数の列 — 等差は足し算、 等比は掛け算で進む

となりとの 差が一定なら 等差数列（an ＝ a1 ＋ (n−1)d）、 となりとの 比が一定なら 等比数列（an ＝ a1rn−1）。 等差は直線、 等比は指数曲線を、 整数の項だけで切り取ったもの。 一般項が分かれば、 何番目の数も一発で求められる。

02

和の公式が、 積み上がりを一発で出す — 分割払いも人口も計算できる

端どうしを組にする発想で等差の和 Sn ＝ n(a1＋an)÷2、 ずらして引く発想で等比の和 Sn ＝ a1(rn−1)÷(r−1)。 この公式が、 毎月の返済額が決まる 分割払いや、 増えてやがて頭打ちになる 人口モデルといった、 現実の見積もりを支えている。

03

デジタル表現と情報量 — 量を段階に直し、 0 と 1 で表す

なめらかな アナログの量を、 一定間隔で測り段階に丸めて デジタルに直す。 段階は 0 と 1（2 進数）で書き、 区別できる場合の数は n ビット ＝ 2n 通り。 写真も音も文字も、 こうして同じ「0 と 1 の列」 になる。 この情報量の考え方が、 これからの情報数理の入口になる。
