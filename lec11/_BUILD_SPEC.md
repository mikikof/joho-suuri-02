## 0. 背骨（絶対に外さない2軸）

### 額縁（発想の転換）— 最初に種まき、最後に回収
- **開き（フック slide-3）**: 長方形＝縦×横、円＝πr² は面積を「知っている」。でも *曲線で囲まれた図形の面積* を、私たちはまだ **定義していない**。この問いを立てる。
- **閉じ（SUMMARY 最終 slide）**: 積分（＝細かく刻んで足した極限＝リーマン積分）を作り終えた今、反転する。**「曲がった図形の面積とは、リーマン積分の値そのものと定める」**。面積があって積分で求めるのではなく、積分が面積を定義する。円環を閉じる。

### 歴史順ストーリー（アルキメデス → 世界各地 → 欧州で花開く → 統合 → 厳密化）

## 3. インタラクティブ仕様（Canvas中心・高DPIは ensureSize 経由）

- **c1 (slide-7) アルキメデスの和**: スライダー=世代 n (0–8)。放物線+内接三角形を世代ごとに敷き詰める。部分和 Sₙ=(4/3)(1−(1/4)^{n+1})。読み: Sₙ、4/3=1.3333…、残り差。三角形1個の面積を1に正規化。
- **c2 (slide-12) カヴァリエリの原理**: スライダー=各段の横ずらし量。左=縦の長方形(短冊積み)、右=ずらした平行四辺形。走査線(可動高さ)で両者の断面幅が常に等しい→面積表示が常に一致。「ずらしても面積は変わらない」。
- **c3 (slide-15・山場) リーマン和**: 関数 y=x² on [0,1]。スライダー n=短冊数(2,4,8,16,32,64,128,200 等)。下限和 L_n=(n−1)(2n−1)/(6n²)、上限和 U_n=(n+1)(2n+1)/(6n²)。真値=1/3=0.3333。両者を色分け、真値を挟む帯、ギャップ U_n−L_n=1/(2n)→0 を表示。検算: n=4→L=0.21875,U=0.46875 / n=50→L≈0.3234,U≈0.3434 / n=200→L≈0.32916,U≈0.33416。
- **c4 (slide-20) 面積関数と基本定理**: 二連。上=y=x² の a=0→x 塗り(x可動)。下=S(x)=x³/3 の曲線に、現在xでの接線(傾き=x²)。読み: f(x)=x²、S(x)=x³/3、dS/dx=x²=f(x)。x=1で S=1/3(c3と一致)を明示。
- **c5 (slide-23) モンテカルロ数値積分**: 曲線 y=x²(または半円で面積=π/4→πでも可)。ボタンで点を撒く(N=100/1k/10k)。囲む矩形[0,1]×[0,1]、下側割合×面積=推定。読み: N、割合、推定面積、真値1/3。「機械学習の期待値もこれ」。※半円版なら π 推定でインパクト大 — 実装時に選択(既定はx²で c3/c4と一貫)。
